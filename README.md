# 私人秘书

面向 iPhone 和 Windows 的个人情报应用，当前包含：

- 河北工程项目设计机会
- A 股每日收盘复盘
- 个人健康日程、饮食与睡眠管理
- 应用内自动提醒
- 健康管理预留模块

## iPhone 安装

应用采用 PWA 形式，不需要 Apple 开发者账号，也不需要 App Store。

1. 使用 iPhone Safari 打开发布地址。
2. 点击 Safari 底部的分享按钮。
3. 选择“添加到主屏幕”。
4. 以后从桌面“私人秘书”图标直接进入。

PWA 会在应用打开或重新回到前台时检查最新日报。手机系统不允许没有服务器的网页在应用彻底关闭时自行唤醒，因此完全免费版本不能像微信那样在后台强制弹窗；当天新日报会在下次打开应用时立即补发提醒。

## Windows 使用

双击 `私人秘书.lnk`，或运行 `start.cmd`。

主秘书提供两个独立窗口：

- 工程情报窗口
- A 股研判窗口

工作日上午 16:30，后台服务会刷新数据并尝试打开主秘书窗口。如果电脑在 16:30 时关机或休眠，则在下次启动服务时补跑。

## 构建免费云端版

仓库已包含 `.github/workflows/daily.yml`。将整个目录上传到 GitHub 公共仓库并启用 Pages 后：

- GitHub Pages 免费提供 HTTPS 地址
- GitHub Actions 每个工作日北京时间 16:30 自动抓取数据
- 不需要购买服务器
- 不需要 API Key
- 不消耗大模型 Token

首次部署时在仓库的 `Settings → Pages → Build and deployment` 中选择 `GitHub Actions`。发布地址在 Actions 的 `deploy` 步骤中显示。

## 工程规则

- 更新频率：每周五 18:00 汇总一次，信息自 2026年7月1日起，保留半年
- 公告阶段：保留公告名称含“设计”的非施工、非监理、非设备采购安装项目，并合并同一项目的招标计划、提前公示和正式公告
- 官方来源：合并河北省招标投标服务平台、河北省公共资源交易中心、河北省发展和改革委员会行政许可公示、雄安新区公共资源交易服务平台
- 新立项记录标记为“新立项·待核实”；金额或资金落实情况未在官方原文披露时不会冒充“符合条件”
- 排除公告：施工招标、土建、施工总承包、EPC、监理，以及设备/材料/物资/货物采购和安装工程、结果及终止公告
- 城市：石家庄、保定、邯郸、沧州、廊坊、衡水、唐山、雄安
- 城市顺序：石家庄 → 保定 → 邯郸 → 沧州 → 廊坊 → 衡水 → 唐山 → 雄安
- 专业：公路、铁路、市政、房建、水利、电力、矿山
- 投资金额：严格大于 1.5 亿元
- 资金落实：只采信官方正文中“资金已落实、已到位”等明确表述
- 同项目公告与更正公告合并，保留最新进展
- 未披露字段标为“待核实”，不猜测、不编造

表格字段：

`项目名称 | 业主单位 | 项目概况 | 近期进展情况 | 投资金额 | 计划招标时间 | 信息来源链接`

## A 股复盘

- 9 个主要指数
- 上证近 30 个交易日走势
- 两市成交额和 20 日量比
- 上涨、下跌、平盘家数
- 涨停、跌停、炸板率、最高连板
- 昨日涨停股票今日表现
- 大盘与中小盘风格
- MA5、MA20、MA60 和 20 日区间
- 领涨与靠后行业
- 主力资金净流入/流出
- 消息面线索
- 下一交易日观察条件
- 次日作战面板：市场状态、情景仓位、主线强弱、龙头候选、开盘确认与失效条件

公开数据接口可能临时限流，应用会标记数据缺口或使用当日最近一次成功抓取的数据，不会用零值冒充真实结果。

## 自动提醒

工程情报固定在每周五 18:00 更新立项和设计招标机会，信息有效期半年，并只在应用内提醒一次。A股复盘提醒可在“工作规则 → 应用内提醒”中设置：

- 提醒时间
- 每天或仅工作日
- 启用或停用

A股到达时间并打开应用时，会显示“今日A股复盘已经准备好”；工程情报只在每周五 18:00 后显示本周立项与设计招标周报。也可以选择 15 分钟后再提醒。

## 健康模块

- 每日饮食建议：按餐盘法自动轮换早餐、午餐、晚餐与加餐。
- 睡眠管理：记录入睡目标、起床时间、实际睡眠时长和睡眠质量。
- 运动管理：每周 150 分钟活动目标、抗阻训练和每日运动记录。
- 身体打卡：饮水、体重、腰围、精力和压力。
- 体检档案：记录体检日期、需要关注的指标和复查日期。
- 健康提醒：早餐、午餐、晚餐和睡前准备时间可在 APP 内设置。
- 健康周报：默认每周日 20:00 推送本周饮食、睡眠、运动、饮水执行情况和下周重点，日期与时间可修改。
- 隐私：健康记录只保存在本机浏览器存储，不上传服务器；可随时导出或清空。

健康管理采用世界卫生组织、疾病控制机构和中国营养学会公开建议，仅用于生活方式管理，不替代医生诊断。
